The desired state of a Sandbox. Set on the `.spec` of a `Sandbox` resource.

## SandboxSpec

| Field | Description | Schema |
|---|---|---|
| `cmd` | Command to run inside the guest. Defaults to the image entrypoint. Immutable. | string[] |
| `cpus` | Number of vCPUs. Raising it live-resizes a running sandbox over the control socket when there is boot headroom, otherwise the sandbox needs a restart to apply it. Default `1`. | integer |
| `desiredState` | Desired lifecycle state. `Stopped` removes the pod but keeps the Sandbox, restartable by setting `Running`. On the current storage model a restart is a fresh boot (guest state is not preserved). Default `Running`. | enum (`Running`, `Stopped`) |
| `entrypoint` | Override the image entrypoint. Empty keeps the image's own entrypoint. Immutable. | string[] |
| `env` | Plain (non-secret) environment variables set in the guest. Immutable. | [EnvVar](#envvar)[] |
| `hostname` | Guest hostname. Immutable. | string |
| `idleTimeoutSecs` | Stop the sandbox after this many seconds with no activity. Immutable. | integer |
| `image` _required_ | OCI image for the guest root filesystem. Immutable. | string |
| `lifecycle` | Wall-clock expiry deadline and policy. Distinct from `maxDurationSecs`/`idleTimeoutSecs`, which bound the guest's own runtime. | [Lifecycle](#lifecycle) |
| `logging` | Guest console log capture, opt-in. Immutable. | [LoggingSpec](#loggingspec) |
| `maxCpus` | Boot-time vCPU ceiling. Unset defaults to `cpus` (no live-resize headroom). The VMM reserves vCPU slots for this count at boot, so raising it after boot requires a new pod. Immutable. | integer |
| `maxDurationSecs` | Hard cap on total sandbox lifetime, in seconds. Immutable. | integer |
| `maxMemory` | Boot-time memory ceiling in MiB. Unset defaults to `memory` (no live-resize headroom). The VMM reserves the virtio-mem hotplug region for this size at boot, so raising it after boot requires a new pod. Immutable. | integer |
| `memory` | Memory in MiB. Raising it live-resizes a running sandbox over the control socket when there is boot headroom, otherwise the sandbox needs a restart to apply it. Default `512`. | integer |
| `network` | Network configuration. Immutable. | [NetworkSpec](#networkspec) |
| `rlimits` | POSIX resource limits applied to guest processes at agentd startup. Immutable. | [Rlimit](#rlimit)[] |
| `runPolicy` | Restart policy on failure. Default `Once`. Immutable. | enum (`Once`, `RerunOnFailure`) |
| `secrets` | Secrets injected as env vars inside the guest via the smoltcp proxy. Immutable. | [SecretEntry](#secretentry)[] |
| `securityProfile` | In-guest hardening applied to exec sessions. Default `Default`. Immutable. | enum (`Default`, `Restricted`) |
| `shell` | Default shell for guest sessions. Immutable. | string |
| `upper` | Writable overlay layer configuration. Immutable. | [UpperSpec](#upperspec) |
| `user` | User the guest workload runs as (name, uid, or `uid:gid`). Immutable. | string |
| `workdir` | Working directory for guest commands. Must already exist in the image, or the sandbox fails to boot. Immutable. | string |
